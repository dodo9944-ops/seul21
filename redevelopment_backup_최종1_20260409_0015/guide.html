2. 작업 로드맵

우리가 처음부터 지금까지 수행한 모든 작업을 단계별로 정리합니다.

Phase 1: 홈페이지 기초 구축

  • HTML5 정적 사이트 40+ 페이지 제작
  • 네이비·골드 프리미엄 디자인 시스템 구축
  • 반응형 레이아웃 (PC/태블릿/모바일)

  • 회사소개 — 조직도, 연혁, 대표 인사말, 사옥 사진

  • 자료실 — 43개 PDF + 20+ HTML 가이드
  • 커뮤니티 — 게시판 (질문/정보/후기/분석/칼럼)
  • 사업성 검토 — 인터랙티브 분석 도구

Phase 3: 서비스 페이지 고도화 (2026-04-07)

  • 재개발 — 일반절차 12단계 + 서울시 신속통합기획 5단계, 현행 도시정비법 반영
  • 재건축 — 일반절차 13단계 + 서울시 신속통합기획 5단계, 안전진단 포함

  • 준비위원회[실무] — 차별화 디자인, 법적 유의사항 포함

13. 자주 묻는 질문

Q: 홈페이지 수정은 어떻게 하나요?

미경이에게 수정 내용을 말하면 됩니다. 코드 수정부터 배포까지 자동 처리합니다.

Q: 배포가 안 되면?

세울 제어판 → 배포 탭에서 로그를 확인하세요. 보통 1~2분 내 반영됩니다.

Q: 홈페이지가 이상하면?

"홈페이지1로 원복" 이라고 말하면 검증된 상태로 즉시 복원됩니다.

Q: 자료실에 파일을 올리려면?

제어판 → 자료실 탭에서 업로드하거나, 미경이에게 말하세요.

Q: 네이버에 검색이 되나요?

네이버 웹마스터 인증 + sitemap 등록 완료. 검색 노출까지 2~4주 소요될 수 있습니다.

Q: SSL 인증서는 갱신해야 하나요?

Vercel이 자동 관리하므로 별도 작업 불필요합니다.
