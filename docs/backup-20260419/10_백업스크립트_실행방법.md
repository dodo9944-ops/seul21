# Windows 원클릭 백업 스크립트 실행 방법

> **이 스크립트 하나로 바탕화면 + Google Drive 양쪽에 자동 백업됩니다.**

---

## 🚀 가장 쉬운 실행 방법 (복사 → 붙여넣기)

### 1단계. 시작 → PowerShell 실행

- 키보드 `Windows 키` 누르기
- `PowerShell` 입력 → `Windows PowerShell` 클릭
- (관리자 권한 **불필요**)

### 2단계. 아래 한 줄을 복사해서 PowerShell 창에 붙여넣고 Enter

```powershell
iwr -useb https://raw.githubusercontent.com/dodo9944-ops/seul21/backup-20260419/docs/backup-20260419/Backup-Seul21.ps1 | iex
```

> 동작:
> 1. GitHub에서 백업 스크립트를 메모리로 내려받기
> 2. 즉시 실행 (파일 저장 없이)
> 3. 바탕화면에 `세울21_백업_YYYYMMDD_HHMM` 폴더 생성
> 4. Google Drive Desktop이 깔려있으면 `00.공유폴더`에도 자동 복사
> 5. 완료 후 탐색기로 폴더 자동 열기

## 🔁 Google Drive 자동 복사 조건

스크립트가 자동으로 Google Drive에 복사하려면 다음 중 하나의 경로에 **Google Drive Desktop**이 동기화되어 있어야 합니다:

- `C:\Users\<사용자>\Google 드라이브\`
- `C:\Users\<사용자>\Google Drive\`
- `G:\내 드라이브\`
- `H:\내 드라이브\`

### Google Drive Desktop이 없다면?
1. https://www.google.com/drive/download/ 에서 설치 (무료)
2. Google 계정으로 로그인
3. 동기화 완료 후 본 스크립트 재실행

### 또는 수동 업로드
1. drive.google.com 접속 (삼성 인터넷 또는 Edge)
2. `00.공유폴더` → `세울21_백업` 폴더 생성 (없으면)
3. 바탕화면의 `세울21_백업_YYYYMMDD_HHMM` 폴더를 **드래그 앤 드롭** 업로드

## ⚠ 실행 중 오류 발생 시

### 오류 A: "이 시스템에서 스크립트를 실행할 수 없으므로..."
→ 스크립트 안에 `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force` 이미 포함됨. 그래도 실패 시 PowerShell 창에서 수동 실행:
```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force
```

### 오류 B: "Invoke-WebRequest: 원격 서버에 연결할 수 없습니다"
- 인터넷 연결 확인
- 회사 방화벽/프록시 환경에서는 다음 경로로 수동 다운로드:
  `https://github.com/dodo9944-ops/seul21/archive/refs/heads/master.zip`

### 오류 C: GitHub 다운로드는 성공하나 Drive 복사 실패
→ Google Drive Desktop 앱 실행 중인지 확인. 동기화 대기 중일 수도 있음 (드라이브 아이콘 상태 확인)

## 💾 추가 수동 백업 권장 대상

스크립트가 접근하지 못하는 외부 자산은 **사용자가 별도 백업**:

| 대상 | 방법 |
|------|------|
| Vercel 환경변수 | Vercel Dashboard → Settings → Environment Variables → 스크린샷 또는 CSV 내보내기 |
| GitHub Secrets | 내용 열람 불가. 원본 발급처에서 재발급 가능하도록 발급처 정보만 기록 |
| Supabase DB 데이터 | Supabase Dashboard → Database → Backups → 매뉴얼 백업 |
| 웹하드 파일 | 외부 웹하드 서비스 다운로드 기능 사용 |
| 도메인(Gabia) | 가비아 계정에서 세금계산서·영수증 PDF 다운로드 |
