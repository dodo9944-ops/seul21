# 홈페이지 설명서 — 페이지별 기능 사양

> **대상 URL**: https://seul21.com

---

## 1. 메인 (index.html)

- **히어로 섹션**: 회사 비전 문구 + CTA 버튼 (상담신청·사업분야 바로가기)
- **주요 서비스 카드**: 6개 사업분야 요약
- **실적 하이라이트**: 최신 업무실적 4건
- **주요뉴스**: 7일 이내 게시된 자료실 뉴스 자동 노출
- **자료실 최신**: 자료실 최신 4건
- **커뮤니티 최신**: 최근 글 미리보기
- **상담 문의 CTA**: 로그인 시 문의 폼 이동, 비로그인 시 로그인 페이지로 유도
- **플로팅 챗봇**: 세울상담사/법률상담/전문가 탭 (전문가는 회원 전용)

- 상세: 모달 또는 별도 페이지로 확장

## 5. 자료실 (library.html)

> 2026-04-18부터 단일 페이지 통합 운영

- **카테고리**: 주요뉴스 / 관계법령(법령·제도+고시·공고 통합) / 서식·가이드 / 투자 / 사례
- **데이터 소스**: `assets/data/mock-data.js` → `MOCK.library` + `MOCK.library2` 통합
- **필터**:
  - 자료실 노출 기간: **1년 (365일)**
  - NEW 뱃지: 7일 이내
- **다운로드 정책**:
  - PDF: `ext` 경로 직접 다운로드 (외부링크 금지)
  - 뉴스/법령/판례: `web` 경로 자체 상세 HTML (외부링크 금지)
- **파일매핑**: `fileMap`, `newsFileMap`
- **카테고리 매핑**: `catDefs`, `_catKeyMap`

## 10. 관리자 영역 (`/admin/`)

로그인 후 접근. 각 섹션별 CRUD UI. 데이터는 GitHub 저장소(`redevelopment/data/*.json`) 또는 `mock-data.js`에 직접 저장.

## 11. 인트라넷 (`/intranet/`)

직원 전용. 프로젝트 관리, 일정, 내부 문서, AI 어시스턴트.

## 12. 공통 컴포넌트

- **헤더** (`common.js` → `headerHTML()`): 유틸바 + GNB + 모바일 탭바 + 드로어
- **푸터**: 회사정보, 서비스 링크, 고객센터, 법적 정보
- **챗봇** (`chatbot.js`): 3탭 (상담/법률/전문가)
- **토스트**: `App.toast()` 공통 알림
- **로그인 체크**: `DataService.isUserLoggedIn()` / `getCurrentUser()`
