## 1. 전체 시스템 구성도

```mermaid

  end

  User -.CDN 로드.-> FA

  Source -->|push 감지·배포| Vercel

  subgraph Backup_Flow[백업 흐름]
    Actions[GitHub Actions<br/>cron·수동]
```

## 2. 페이지 로드 흐름

```mermaid
sequenceDiagram
  participant B as 브라우저
  participant D as DNS(가비아)
  participant V as Vercel
  participant G as GitHub
  B->>D: seul21.com DNS 조회
  D-->>B: Vercel IP
  B->>V: GET / (index.html)
  V-->>B: HTML + common.css + common.js
  B->>V: GET /assets/data/mock-data.js?v=...
  V-->>B: MOCK 데이터 (자료실·실적·구역)
  B->>V: GET /api/community?limit=5
  V->>G: GitHub Contents API GET community.json
  G-->>V: JSON
  V-->>B: 최신 글 5건
  Note over B: 렌더 완료
```

## 3. 커뮤니티 글 작성 흐름

```mermaid
sequenceDiagram
  participant U as 회원
  participant V as Vercel Fn
  participant G as GitHub
  participant T as Telegram Bot
  U->>V: POST /api/community {title, content}
  V->>G: GET data/community.json (sha 포함)
  G-->>V: 기존 JSON
  V->>V: 새 글 prepend + ID 생성
  V->>G: PUT data/community.json (new content, prev sha)
  G-->>V: 저장 완료
  V->>T: sendMessage(알림 포맷)
  T-->>V: ok
  V-->>U: 201 Created {id}
  U->>U: localStorage에 즉시 저장
```

## 4. 자료실 다운로드 흐름

```mermaid
sequenceDiagram
  participant U as 방문자
  participant B as library.html
  participant F as fileMap
  U->>B: 자료 카드 클릭
  B->>F: lookup(id)
  alt ext 경로 (PDF)
    F-->>B: {ext: '../downloads/files/xxx.pdf'}
    B->>U: a.download 트리거 (즉시 다운로드)
  else web 경로 (뉴스·법령·판례)
    F-->>B: {web: '../downloads/news_YYYYMMDDa.html'}
    B->>U: location.href 이동 (자체 HTML 페이지)
  else 미등록
    B->>U: 토스트 "파일 준비 중입니다"
  end
```

## 5. AI 챗봇 흐름

```mermaid
sequenceDiagram
  participant U as 사용자
  participant C as chatbot.js
  participant V as /api/chat
  participant A as Anthropic
  U->>C: 질문 입력

  V-->>C: text 스트림
  C-->>U: UI에 타이핑 표시
```

## 6. 네트워크 포트·프로토콜

| From | To | Protocol | Port |
|------|-----|---------|------|
| 방문자 | seul21.com | HTTPS | 443 |
| Vercel | GitHub API | HTTPS | 443 |
| Vercel | Telegram API | HTTPS | 443 |
| Vercel | Anthropic API | HTTPS | 443 |
| GitHub Actions | Google Drive API | HTTPS | 443 |
| Vercel | Supabase | HTTPS (PostgREST) | 443 |

모든 통신은 TLS 1.2+ 암호화.

## 7. 장애 격리 지점

| 단일 장애점 | 영향 | 대체 |
|-------------|------|------|
| 가비아 DNS | 전체 사이트 접속 불가 | DNS 장애는 복제 방지 — 보조 DNS 검토 |
| Vercel | 전체 사이트 다운 | 대체 호스팅 사전 준비 필요 |
| GitHub API rate limit | 커뮤니티·문의 저장 실패 | 5000 req/h (authenticated) — 충분 |
| Telegram | 알림만 실패 | 본문 정상 저장됨 (비동기 try-catch) |
| Anthropic | AI 챗봇만 실패 | 일반 상담 폼으로 유도 |
