단계별 절차

①정비계획 수립 단계

  • 입안 요청: 주민 30% 이상 동의 + 자치구 의회 의견 청취
  • 기초조사 → 정비계획안 작성 → 주민 공람·공고(30일 이상)
  • 도시계획위원회 심의 → 구역 지정 고시
  • 신통기획 구역은 서울시 공공주도로 2년 이내 완료 목표

②추진위원회 구성 단계

  • 토지등소유자 50% 이상 동의 → 추진위 구성 승인 신청
  • 자치구청장 승인 → 추진위원회 운영 개시
  • 개략적 사업시행계획서 고지 의무 (2025.06.04 개정 신설)

③조합설립인가 단계

  • 재개발: 토지등소유자 4/5 이상 동의
  • 재건축: 토지등소유자 및 구분소유자 각 3/4 이상 동의 (2026년 일부 완화)
  • 창립총회 개최 → 조합설립인가 신청 → 인가 고시

④사업시행인가 단계

  • 건축계획·배치도·분양계획 등 포함 사업시행계획 수립
  • 통합심의(건축·경관·교통·재해) 동시 신청 — 서울시 2026년 확대 적용
  • 사업시행인가 → 관계 행정기관 협의

⑤관리처분인가 단계

  • 종전자산 감정평가(조합원 개별 통보)
  • 분양 신청(60일 이상 신청 기간) → 관리처분계획 총회 의결
  • 관리처분인가 신청·고시 → 분양 미신청 조합원 현금청산

⑥이주·철거·착공·준공

  • 이주 보상 협의 → 철거 허가 → 착공 신고
  • 준공인가 신청 → 준공인가 고시 → 이전 고시 → 보존등기

2026년 주요 개정 사항

2026.01.02 시행 도시정비법(법률 제21078호) 및 관련 하위 법령 개정으로 재건축 동의율 완화, 재건축진단 현지조사 폐지, 통합심의 확대 등이 실무에 적용됩니다.
  • 재건축 조합설립 동의율 완화 (기존 3/4 → 구역별 조건 확인 필요)
  • 재건축진단 현지조사 완전 폐지 (2026.06.04 시행)
  • 30년 경과 단지 재건축진단 간소화 — 정비계획 수립 가능
  • 전자동의 시스템 도입 예고 (2026.12.04 예정)

실무 참고

  • 단계별 처리 기한은 자치구·사업 규모에 따라 상이
  • 사업시행인가 신청 전 서울시 도시계획포털(urban.seoul.go.kr)에서 동일 구역 선례 확인 권장
  • 분쟁 발생 시 서울시 정비사업 분쟁조정위원회 신청(무료) 활용
  • 한국감정원 공사비 검증 의뢰로 객관적 공사비 적정성 확인 가능
