판례·질의회신

재건축·재개발 조합원 서면 의결권 행사 후 총회 직접 참석 — 도정법 제45조 "직접 출석" 해당 여부 유권해석

법제처 2026년 법령해석 사례 · 6월 9일 수록

자료 개요

법제처 유권해석(법령해석 사례). 재건축·재개발 정비사업 조합원이 서면결의서(우편)를 사전 제출한 뒤 실제 총회에 직접 참석한 경우, 「도시 및 주거환경정비법」 제45조 제6항의 「조합원의 직접 출석」으로 보아 출석 정족수를 충족한 것으로 볼 수 있는지 여부에 관한 법제처 해석이다.

주요 내용

① 질의 요지

  • 조합원 갑이 서면결의서를 미리 제출한 후 해당 총회에 직접 출석한 경우
  • 갑이 서면 출석인지 직접 출석인지가 쟁점
  • 도정법 제45조 제6항은 총회 의결 시 조합원의 직접 출석을 원칙으로 하고, 서면결의·대리인 출석을 제한적으로 허용

② 법제처 해석

  • 조합원이 서면결의서 제출 후 직접 총회에 출석한 경우 → 직접 출석으로 보아야 함
  • 서면결의서 효력은 직접 출석으로 소멸(대체)
  • 서면 제출과 직접 참석이 병존하면 직접 출석이 우선
  • 출석 정족수 및 의결 정족수 계산 시 직접 출석자로 산입

③ 실무 의미

  • 총회 당일 갑작스럽게 참석 가능해진 조합원이 이미 서면결의서를 제출했더라도 직접 참석하여 의결권 행사 가능
  • 조합 사무국은 직접 참석 조합원을 사전 서면결의서 제출 여부와 무관하게 직접 출석으로 처리

④ 대리인과의 관계

  • 대리인이 위임장을 가져온 상태에서 본인도 참석한 경우 → 본인(직접 출석) 우선, 위임장 효력 소멸 처리

⑤ 관련 조문

  • 도시 및 주거환경정비법 제45조 (총회의 의결)
  • 도시 및 주거환경정비법 제45조 제6항 (직접 출석 원칙)
  • 도시 및 주거환경정비법 시행령 제40조 (서면결의 방법)

실무 참고

  • 조합 총회 준비 시 서면결의자 목록을 실시간 업데이트하여 직접 참석자와 중복 처리 방지 시스템 마련 권장
  • 총회 접수 창구에 "서면결의서 제출 후 직접 참석 시 서면결의 자동 취소" 안내문 배치 권장
  • 의결 정족수 산정 시: 직접 참석자 + 대리인(대리 참석) + 서면결의자(직접 참석 아닌 경우만) 합산
  • 법제처 법령해석 사례 전문 조회: moleg.go.kr/menu.es?mid=a10106020000
