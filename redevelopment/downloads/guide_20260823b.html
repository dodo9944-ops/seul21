주요 내용

① 5대 핵심 서비스 개요

  • 서비스 1 정보공개 — 도정법 §124 의무 공시: 계약서·회계장부·총회 의사록 공개
  • 서비스 2 조합업무지원 — 전자결재·내부 공문·회의록 관리 시스템
  • 서비스 3 분담금추정 — 조합원별 예상 분담금 자동 산정 기능
  • 서비스 4 종합포털 — 구역별 진행 현황·일정·공지 통합 조회
  • 서비스 5 시스템관리자 — 조합 관리자 권한 설정·이용자 등록 관리

② 예산회계 전자화 활용법

2026년부터 서울시 내 모든 정비사업 조합은 예산·회계 장부를 정보몽땅 시스템에 전자 등록해야 하며, 이를 통해 조합원이 실시간으로 열람할 수 있습니다. (도정법 §124 개정 반영)
  • 예산서·결산서 등록: 회계연도 종료 후 3개월 이내 (매년 3월 말)
  • 계약서 등록: 5,000만원 이상 계약 체결 후 10일 이내 의무
  • 자금 지출 내역: 월별 자동 정리 → 조합원 조회 가능
  • 회계 감사 결과: 감사 완료 후 14일 이내 등록

③ 총회 관리 기능

  • 총회 공고문 등록: 총회 개최 14일 전 시스템 등록 → 자동 조합원 공지
  • 전자 투표 연동: 온라인 전자 총회 개최 시 정보몽땅 전자투표 시스템 활용
  • 의사록 등록: 총회 종료 후 15일 이내 조합원 열람 가능
  • 총회 안건 이력 관리: 창립총회부터 모든 총회 안건·결과 이력 보관

④ 분담금 추정 서비스 활용

  • 조합원별 종전자산평가액 입력 → 권리가액 자동 산정
  • 분양예정 주택 유형별 분양가 입력 → 분담금 자동 계산
  • 추정 결과 PDF 출력 → 조합원 개별 안내 자료로 활용
  • 시뮬레이션 기능: 사업비 변동 시나리오별 분담금 비교 가능

⑤ 도정법 제124조 공시 의무 체크리스트

  • 조합 설립 관련: 정관·임원 명단·선정 경위 공시
  • 사업시행 관련: 사업시행계획서·감정평가서·정비사업비 내역
  • 총회 관련: 총회 의사록·결의 사항·참석 현황
  • 회계 관련: 예·결산서·감사 결과·주요 계약서
  • 분양 관련: 분양공고문·분양신청 결과·관리처분계획
