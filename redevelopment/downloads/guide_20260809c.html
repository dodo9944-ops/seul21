주요 내용

① 공사비 분쟁 발생 시 단계별 대응 흐름

핵심 원칙: 시공사 공사비 증액 요청 → 즉시 한국부동산원 검증 신청 → 검증 결과로 협상 → 결렬 시 분쟁조정위원회 신청
[1단계] 증액 요청 수령시공사 증액 공문 접수 후 즉시 법률·기술 자문팀 구성
[2단계] 검증 신청한국부동산원 또는 SH공사에 공사비 검증 신청 (서류 준비)
[3단계] 검증 결과 수령60일 이내 결과 수령 → 적정 공사비 범위 확인
[4단계] 협상 진행검증 결과를 근거로 시공사와 공사비 재협상
[5단계] 협상 결렬 시분쟁조정위원회(도정법 제116조의2) 조정 신청
[6단계] 조정 성립재판상 화해 효력 발생 — 양 당사자 구속력

③ 공사비 검증 신청 시 필수 준비 서류

  • 공사비 검증 신청서 (한국부동산원 소정 양식 — reb.or.kr 다운로드)
  • 공사도급계약서 사본 (기존 계약 및 변경 계약 포함)
  • 시공사 공사비 증액 요청서 원본
  • 인허가 서류 (사업시행계획인가·관리처분계획인가 결정서 사본)
  • 설계도면 (변경 전·후 비교 가능한 형태)
  • 공사비 내역서 (공종별 물량·단가·금액 상세)

④ 분쟁조정위원회 조정 신청 (협상 결렬 시)

  • 근거 법령: 도시정비법 제116조의2
  • 신청처: 서울시 주거정비과 02-2133-7176
  • 조정 성립 요건: 쌍방 합의 → 재판상 화해 효력 (집행력 있는 화해 조서 효력)
  • 조정 불성립 시: 민사소송 또는 중재 등 별도 법적 절차 진행
  • 검증 결과를 조정 신청 자료로 활용 — 증거 레버리지 극대화

⑤ 공사비 분쟁 예방 체크리스트

  • 공사도급계약 체결 전 공사비 사전 검증 신청 (도정법 제29조의2 — 변경 전도 가능)
  • 계약서 물가 변동 조정(에스컬레이션) 조항 명확화 — 임의 증액 차단
  • 공사비 내역서 공종별·공기별 단가 분리 계약 (추후 검증 효율화)
  • 정기 공사비 모니터링 위원회 구성 (조합 내 기술 검토 역량 강화)
  • 계약 변경 시 반드시 조합 총회 의결 확인 (임원 전결 금지)
