주요 내용 — 단계별 업무 해설

① 재건축 요건 확인

  • 준공 후 30년 이상: 2026.05.01 개정으로 안전진단 없이 재건축 허용 (단, 구조·기능 결함 있으면 안전진단 유지)
  • 안전진단 미해당 시 정비계획 수립 단계 직행 가능
  • 안전진단 결과 D·E등급: 재건축 승인. C등급 이상: 조건부 또는 불가

② 안전진단 절차

  • 국토부 인정 안전진단기관 선정 (KISCON 인정기관 목록 확인)
  • 현지조사 단계: 2026.06.04 이후 폐지 예정 → 서류·실측 평가만으로 진단 완료
  • 결과 통보 후 시장·군수의 적정성 검토 (불합격 시 이의신청 30일)
  • 재진단: 3년 이내 기존 보고서 재활용 가능 (2026.06.04 시행)
2026.06.04 시행: 현지조사 절차가 폐지됩니다. 6월 4일 이후 안전진단을 신청하는 단지는 현지조사 없이 서류·실측 평가만으로 진단이 완료됩니다.

③ 정비계획 수립·정비구역 지정

  • 자치구 용역 발주 → 기초조사 → 도시계획위원회 심의 → 지정 고시
  • 신통기획(신속통합기획) 적용 시: 5~7년 → 2~3년 단축
  • 신통기획 신청: 주민 30% 이상 동의 + 노후도 67% 이상 요건

④ 추진위원회 구성 (2026.06.04 이후 조기 구성 가능)

  • 토지등소유자 50% 이상 동의 → 자치구 추진위 승인 → 추진위 활동 개시
  • 2026.06.04 이후: 정비구역 지정 전에도 추진위 구성 가능 (도시정비법 시행령 개정)
  • 추진위 구성 후 2년 이내 조합설립인가 신청 의무

⑤ 조합설립인가

  • 재건축 동의율: 70% (2026.05.01 개정, 구 75% → 현 70%)
  • 재개발 동의율: 75% (유지)
  • 창립총회 → 조합설립인가 신청 → 자치구 처리 (60일 이내)
  • 기존 75% 미달 단지 즉시 재추진 가능

⑥~⑧ 사업시행인가 → 관리처분인가 → 준공

  • 사업시행인가: 사업시행계획서·건축심의·교통영향평가·주민공람(30일)
  • 관리처분인가: 복수 감정평가 → 분양신청(30~60일) → 관리처분계획 총회 의결 → 인가
  • 이주·철거·착공: 이주비 대출 집행 후 착공. 이주 기간 60일 이상
  • 준공·사용검사 → 입주 → 조합 해산·청산
