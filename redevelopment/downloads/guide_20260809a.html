주요 내용

① 전자총회·전자투표 법적 요건 (도정법 제45조·제73조)

도정법 제45조: 조합원은 총회에서 전자적 방법으로 의결권을 행사할 수 있다. 단, 정관 또는 시행령이 정하는 방법·절차를 준수해야 한다.
  • 조합 정관에 전자투표 허용 조항 반드시 사전 반영 (정관 변경 절차 필요)
  • 전자서명법상 본인인증 수단 사용 필수 (PASS, 카카오, 공동인증서 등)
  • 투표 기간: 총회 개최일 전 7일 이상 확보 (서울시 권고 — 법령 최소 기간 확인 필수)
  • 투표 결과의 무결성·보안 보장: 암호화 전송, 개인정보 보호 기술 적용 필수
  • 서면 투표와 전자 투표 병행 가능 (조합원 선택권 보장)

② 전자투표 플랫폼 선정 기준

  • 전자서명법 인증 수단 지원 여부 (PASS·카카오·공동인증서 중 2종 이상 권장)
  • 조합원 인증·본인확인 API 연동 안정성 (이통사 점검 이력 등)
  • 투표 결과 데이터 암호화 및 실시간 집계 기능
  • 비용 구조 투명성 (건당 과금 / 정액제 / 운영비 포함 여부)
  • 서울시 지원사업 공인 플랫폼 목록 사전 확인 (최신 공고 기준)
  • 고령·비스마트폰 조합원 대비 서면 병행 대응 방안 보유 여부

③ 도입 단계별 절차

  • [1단계] 정관 검토·변경: 전자투표 허용 조항 반영 → 임시총회 의결
  • [2단계] 플랫폼 선정: 입찰·견적 비교 → 서울시 지원 여부 확인 → 계약
  • [3단계] 서울시 지원사업 신청: cleanup.seoul.go.kr / 주거정비과 신청
  • [4단계] 조합원 사전 안내: 전자투표 방법·인증 수단·일정 공지 (7일 이상)
  • [5단계] 총회 개최: 전자투표 + 서면 병행 → 결과 집계 → 의사록 작성
  • [6단계] 결과 보고: 시·군·구청 도시정비과 결과 보고 (총회 의결 필요 사안)

④ 조합원 참여 설계 핵심 포인트

  • 투표 기간 7일 이상 확보 — 충분한 접근 기회 보장
  • 문자·모바일 앱·카카오톡·서면 공지 동시 발송으로 접근성 극대화
  • 고령 조합원 전담 안내 채널 운영 (지점 방문, 전화 안내 병행)
  • 1:1 모의 투표 체험 서비스 운영 (본 투표 전 플랫폼 친숙도 향상)
  • 투표 독려 문자 1~2회 발송 (마감 D-3, D-1 기준)
