주요 내용

① 기존 문제 및 개선 배경

재개발·재건축 현장에서 입안요청·추진위원회 구성·조합설립인가 단계마다 서식이 달라 토지등소유자가 동의서를 각각 제출해야 했습니다. 이번 개선으로 입안요청 단계 1회 제출로 이후 모든 단계에 동일 서식을 적용합니다.
  • 재개발: 입안요청 단계 1회 제출 → 추진위원회 구성·조합설립인가까지 갈음
  • 재건축: 입안제안 단계 1회 제출 → 전 단계 통합 적용
  • 기존 제출 동의서: 내용 변경 없으면 종전 서식 그대로 활용 가능

② 표준서식 필수 기재사항

  • 필수신청 구역 위치 — 법정동·지번 목록
  • 필수대표소유자 지정 — 성명·주민등록번호·주소·연락처
  • 필수공유자 전원 서명·날인
  • 필수각 공유자의 지분 비율
  • 필수동의 일자 및 유효 기간(동의한 날부터 2년, 도시정비법 시행령 제28조)

③ 서식 사용 시 주의사항

  • 공유 지분이 변동된 경우(매매·상속·증여 등) 반드시 새 서식으로 재제출 필요
  • 최대지분자가 아닌 공유자가 대표소유자로 기재된 경우 효력 없음(법제처 유권해석)
  • 입안요청 이전에 미리 징구한 기존 서식도 이 통합 서식으로 대체 가능
  • 동의서는 반드시 법정서식(시행규칙 별지)을 사용해야 자치구 수리 가능

④ 서식 다운로드 경로

  • 서울시 정비사업 정보몽땅(cleanup.seoul.go.kr) → 자료실 → 「서식·서류」 카테고리
  • 검색어: "대표소유자 선임동의서 표준서식" 또는 "선임동의서 일원화"
  • 제공 형식: HWP(한글) · PDF 무료 다운로드
  • 자치구·추진주체·주민 누구나 동일 기준으로 사용 가능

실무 참고

  • 입안요청 전 서식 징구 시 이 통합서식을 사용하면 이후 단계에서 재징구 불필요
  • 서울시 자치구 도시정비과 경유 처리 — 각 자치구 담당 팀 문의
  • 관련 문의: 서울시 주거정비과 02-2133-7204
  • 서울특별시 도시정비조례 별지서식과 병행 확인 권장
