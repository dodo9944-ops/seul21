주요 내용

① 사업시행계획인가 신청서 (별지 제11호)

  • 신청인: 조합 또는 사업시행자 (시장·군수에 제출)
  • 첨부 서류: 정비구역 위치도, 사업시행계획서, 설계도서, 총회의사록, 토지 사용 동의서, 안전진단결과보고서 사본
  • 신청 전 필수 사전 절차: 주민공람(30일 이상), 건축심의, 교통영향평가, 사전재해영향성 검토 완료
  • 처리 기한: 신청일로부터 60일 이내 (연장 가능)

② 조합원 명부 (별지 제12호)

  • 기재 항목: 성명, 주소, 소유 토지 소재지, 면적, 취득일, 조합원 자격 구분
  • 사업시행인가 신청 시 최신 현황 반영본 첨부 의무
  • 변경 발생 시 30일 이내 업데이트 의무

③ 총회 의사록 (별지 제13호)

  • 총회 개최 통지 기간: 14일 전 이상 (안건·일시·장소 명시)
  • 의결 정족수: 조합원 과반 출석 + 출석 과반 찬성
  • 전자의결권 적용 시 추가 기재: 전자서명 동의 수, 직접 출석 환산 방식 (2026.05.01 개정 신설)
  • 의사록 작성 후 14일 이내 조합원 열람 공개 의무
2026.05.01 개정 신설: 전자서명으로 제출한 서면결의서는 직접 출석으로 인정됩니다. 전자의결 적용 시 총회 의사록에 전자서명 동의 수와 환산 방법을 반드시 기재하세요.

④ 시공자 선정 의결서 (별지 제15호)

  • 경쟁입찰: 입찰 방식·응찰 업체·배점표·평가 결과·의결 내용 기재
  • 수의계약 전환 시: 유찰 횟수 확인(2회 이상), 유찰 공고문 첨부, 서울시 공사비 검증 결과서(700만원/3.3㎡ 초과 시 필수) 첨부
  • 의결 정족수: 조합원 과반 동의 (일반 의결)

실무 참고사항

  • 사업시행인가 신청 전 사업시행계획서 주민공람 30일 이상 필수
  • 총회 의사록은 공증이 필요한 경우 자치구 건축과 사전 확인
