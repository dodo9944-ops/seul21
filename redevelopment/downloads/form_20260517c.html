의무화 배경

핵심: 2026년 5월 1일 도시정비법 개정으로 공사비가 3.3㎡당 700만원을 초과하는 정비사업장은 시공자 선정 또는 공사비 변경 전에 서울시 공사비 검증위원회의 사전 검증을 의무적으로 거쳐야 합니다. 수의계약 전환 시에도 선행 의무입니다.

주요 내용

① 검증 의무 대상

적용 기준3.3㎡당 700만원(공급면적 기준) 초과 시
적용 시점시공자 선정 입찰 전 또는 공사비 변경 협의 시
수의계약2회 유찰 후 수의계약 전환 전 사전 검증 필수
검증 결과조합 총회에서 공개 의무 (서울시 기준)

② 신청 주체 및 제출처

  • 신청 주체: 조합 또는 사업시행자 (시공자 대신 신청 불가)
  • 제출처: 해당 정비사업 구역 관할 자치구청 → 서울시 주거정비과 경유
  • 신청 시기: 입찰안내서 공고 전 검증 완료 권장

③ 제출 서류 목록

  1. 공사비 검증 신청서 (별지 제1호 — 정비사업 정보몽땅 서식 다운로드)
  2. 공사비 내역서 (항목별 공사비 내역 Excel + PDF 병행 제출)
  3. 설계도서 일식 (기본설계 도면 일체 — 평면도·입면도·배치도 포함)
  4. 시공자 공사비 제안서 원본 (입찰 제안서 또는 협의 요청서)
  5. 단지 기본현황서 (세대수·평형·공급면적 현황, 건축 개요)
  6. 기존 계약서 사본 (공사비 변경 신청 시만 해당)

④ 검증 절차 및 기간

  • 접수 자치구청 접수 → 서울시 주거정비과 전달
  • 검토 공사비 검증위원회(외부 전문가 위원) 심의
  • 보완 필요 시 서류 보완 요청 (보완 기간은 60일에 미산입)
  • 결과 접수일로부터 60일 이내 결과 통보
  • 이의 결과 이의신청 30일 이내 가능

실무 참고사항

  • 총회 전 공사비 검증 결과 미확보 시 총회 의결 효력 논란 발생 가능 — 선행 필수
  • 시공자 선정 입찰안내서 작성 단계부터 700만원 기준 충족 여부 사전 검토 권장
  • 공사비 검증 소요 최대 60일 + 보완 기간 → 입찰 일정에 최소 3개월 여유 확보 필요
  • 검증 신청 전 SH공사 공사비 검증 안내사무소(무료) 사전 상담 활용 가능
  • 최신 신청서 서식: 정비사업 정보몽땅 cleanup.seoul.go.kr 자료실 → 서식 탭
