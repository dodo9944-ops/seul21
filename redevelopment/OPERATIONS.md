# (주)세울엔지니어링 홈페이지 운영지침

**문서번호:** SEUL-OPS-2026-001
**시행일:** 2026-04-09
**관리자:** 대장 (이창우)
**운영담당:** 미경 (AI 비서)

---

## 제1조 (목적)
본 지침은 세울엔지니어링 홈페이지(seul21.vercel.app)의 자료실 및 주요뉴스 운영, 경쟁사 모니터링, 관리자 보고에 관한 기준을 정한다.

## 제2조 (운영 대상)
1. 홈페이지 자료실 (법령·판례·서식·가이드·지침)
2. 홈페이지 주요뉴스
3. 경쟁사 및 타 정비사업 사이트 모니터링
4. 관리자 텔레그램 보고

## 제3조 (주요뉴스 업데이트 기준)
1. 매일 오전 6시에 자동 업데이트한다.
2. 대상: 재개발, 재건축, 소규모재건축, 가로주택정비사업, 도시정비, 정비사업 정책, 조합, 시공사, 인허가, 분담금, 관리처분, 사업시행인가, 착공, 준공, 이전고시 등 정비사업 관련 뉴스
3. 수집처:
   - 네이버 뉴스 검색
   - 구글 뉴스 검색
   - 주요 신문사 및 언론사 웹사이트
   - 국토교통부·서울시 등 공공기관 보도자료
4. 최신 기사와 주요 보도자료를 우선 수집한다.
5. 중복 기사, 단순 복제성 기사, 광고성 기사, 신뢰도 낮은 정보는 제외한다.
6. 각 뉴스에는 제목, 요약, 출처, 원문 링크, 게시일을 반드시 포함한다.
7. 요약은 과장 없이 핵심 사실 위주로 정리한다.
8. 법률적 판단이나 확정적 해석은 넣지 않고 사실 전달 중심으로 작성한다.

## 제4조 (게시 및 검수 기준)
1. 수집 후 라이브 홈페이지에 실제 게시한다.
2. 게시 후 반드시 다음을 검수한다:
   - 메인 및 주요뉴스 영역 정상 노출 여부
   - 제목 클릭 시 링크 정상 연결 여부
   - 출처 표기 누락 여부
   - 모바일 및 PC 정상 표시 여부
3. 오류 발생 시 정상 작동할 때까지 수정 후 재확인한다.
4. 라이브 페이지에서 정상 동작 확인 완료 시에만 작업 완료로 처리한다.

## 제5조 (텔레그램 보고)
1. 매일 오전 7시에 텔레그램으로 관리자(대장)에게 보고한다.
2. 보고 내용: 작업구분, 실행 여부, 게시 건수, 대표 기사 제목, 출처·링크 정상 여부, 오류 여부, 최종 조치 결과, 처리 완료 시각
3. 오류 발생 시 수정 내역도 함께 보고한다.
4. 관리자 확인이 가능하도록 구체적으로 작성한다.

### 텔레그램 보고 템플릿
```
[세울 홈페이지 주요뉴스 관리보고]
━━━━━━━━━━━━━━━━━━━━
- 작업구분: 주요뉴스 일일 업데이트

  1) 기사 제목 (출처)

- 출처표시: 이상 없음 / 누락 N건 수정 완료
- 링크작동: 전건 정상 확인 / 오류 N건 수정 완료

```

## 제6조 (자료실 관리)
1. 대상: 법령·제도, 정비사업 절차, 판례·질의회신, 실무가이드, 공문서식
2. 정확성, 출처 명시, 최신성을 충족하여야 한다.
3. 미검증 정보, 내부자료, 개인정보 포함 자료는 등록 금지한다.
4. 법령·제도 자료는 변경 시 즉시 수정한다.
5. 일반 자료는 분기 1회 이상 정기 점검한다.

## 제7조 (타 사이트 모니터링)
1. 3일마다 1회 점검한다.
2. 점검 항목: 주요뉴스 운영 방식, 자료실 구성, 업무실적 노출, 상담 유도 방식, 문구·콘텐츠 흐름, 디자인 변경, 신규 게시물
3. 세울 홈페이지 반영 가능한 시사점 중심으로 정리한다.
4. 즉시 반영 가능 / 검토 필요 / 참고만 할 사항으로 구분한다.

### 타 사이트 점검 보고 템플릿
```
[타 사이트 3일 점검 보고]
━━━━━━━━━━━━━━━━━━━━
- 점검일: YYYY-MM-DD
- 점검대상: N개 사이트
- 시사점:
  ■ 즉시 반영 가능: (내용)
  ■ 검토 필요: (내용)
  ■ 참고만 할 사항: (내용)
━━━━━━━━━━━━━━━━━━━━
```

## 제8조 (민감정보 관리)
1. 텔레그램 보고에서 민감정보 및 비공개 정보는 제외 또는 마스킹 처리한다.
2. 관리자 보고용 메시지와 사용자 노출용 게시 문구는 분리한다.

# 제2편 커뮤니티 관리지침

**문서번호:** SEUL-COM-2026-001
**시행일:** 2026-04-09
**관리자:** 대장 (이창우)
**운영담당:** 미경 (AI 비서)

---

## 제9조 (목적)
본 지침은 세울엔지니어링 홈페이지 커뮤니티의 건전한 운영 및 신뢰성 확보, 정비사업 관련 정보 공유 및 사용자 참여 활성화, 허위정보·민원성 게시글·분쟁 요소 사전 차단을 위한 기준을 정한다.

## 제10조 (운영 대상)
커뮤니티 전체 게시판을 대상으로 한다.
- 질문·답변
- 정보공유
- 후기·경험
- 분석·칼럼

## 제11조 (게시글 유형 구분)
1. 질문·답변: 정비사업 절차, 법령, 사업 유형 관련 질의
2. 정보공유: 뉴스, 제도 변화, 실무 정보 공유
3. 후기·경험: 조합원 경험, 사업 진행 사례
4. 분석·칼럼: 정비사업 정책, 시장 흐름, 제도 분석

## 제12조 (게시 기준)
게시글은 다음 기준을 충족하여야 한다.
1. 사실 기반 내용일 것
2. 특정 개인 또는 단체를 비방하지 않을 것
3. 법률 해석은 확정적 표현을 사용하지 않을 것
4. 정비사업 관련 정보는 객관적으로 서술할 것
5. 광고 및 영업 목적 게시글은 제한한다

## 제13조 (게시 금지 사항)
다음 각 호의 게시글은 즉시 삭제 또는 비공개 처리한다.
1. 허위 정보 또는 미검증 정보
2. 욕설, 비방, 명예훼손, 분쟁 유발 글
3. 특정 조합, 시공사, 개인에 대한 공격성 게시글
4. 개인정보 포함 글 (이름, 전화번호, 주소 등)
5. 계약내용, 내부자료, 비공개 문서
6. 광고 및 홍보 목적 게시글
7. 동일 내용 반복 게시 (도배)

## 제14조 (AI 관리 기준)
커뮤니티는 AI 보조 운영을 적용한다.

### AI 역할
1. 게시글 자동 분류
2. 게시글 요약 생성
3. 부적절 게시글 탐지
4. 답변 초안 생성
5. FAQ 자동 축적

### AI 제한
1. 법률 확정 해석 금지
2. 분담금, 권리가액 등 민감 수치 판단 금지
3. 특정 사업지에 대한 단정적 평가 금지

## 제15조 (게시글 검수 및 처리 절차)
모든 게시글은 다음 절차를 따른다.
1. 게시글 등록
2. AI 1차 분류 및 위험도 판단
3. 관리자 검토 (필요 시)
4. 공개 / 수정 / 비공개 / 삭제 처리

분쟁 가능성 게시글은 반드시 관리자 검토 후 공개한다.

## 제16조 (댓글 및 답변 관리)
1. 답변은 사실 기반으로 작성한다.
2. 법률적 판단이 필요한 경우 "전문 상담 권유"로 유도한다.
3. 공격적 댓글은 즉시 삭제 또는 비공개 처리한다.
4. 동일 질문 반복 시 FAQ로 전환한다.

## 제17조 (민원 및 분쟁 대응)
다음 경우 즉시 관리자 개입 대상이다.
1. 조합 분쟁 관련 게시글
2. 시공사, 조합, 특정인 비방
3. 법적 분쟁 가능성 있는 내용
4. 동일 사용자의 반복 민원

처리 방식:
- 게시글 비공개 전환
- 관리자 직접 답변
- 필요 시 상담 연결

## 제18조 (텔레그램 보고)
다음 항목 발생 시 관리자에게 텔레그램 보고한다.
1. 부적절 게시글 탐지
2. 삭제 또는 비공개 처리
3. 분쟁 가능 게시글 발생
4. 반복 민원 사용자 발생
5. AI 답변 실패

### 커뮤니티 텔레그램 보고 템플릿
```
[세울 커뮤니티 관리보고]
━━━━━━━━━━━━━━━━━━━━
- 작업구분: (게시글 삭제 / 비공개 전환 / 분쟁 대응 / AI 답변 실패)
- 처리결과: (완료 / 진행 중 / 관리자 확인 필요)
- 대상: (게시글 제목 또는 사용자)
- 요약: (상황 요약)
- 상태: (공개 / 비공개 / 삭제)
- 후속조치 필요 여부: (있음 / 없음)
━━━━━━━━━━━━━━━━━━━━
```

## 제19조 (정기 관리)
1. 게시글 및 댓글은 주 1회 이상 점검한다.
2. 부적절 게시글은 즉시 조치한다.
3. FAQ는 지속적으로 업데이트한다.
4. 커뮤니티 활성화를 위해 주요 질문은 자료실과 연계한다.

## 제20조 (운영 원칙)
1. 커뮤니티는 정보 제공 목적이며 법률 자문 기능이 아니다.
2. 모든 답변은 참고자료 수준으로 제공한다.
3. 전문 상담이 필요한 경우 고객센터로 유도한다.

## 제23조 (공고 수집 기준)
1. 수집처:
   - 서울시 정비사업 정보몽땅 (cleanup.seoul.go.kr)
   - 나라장터 G2B (g2b.go.kr)
   - 기타 공공기관 및 관련 발주기관 사이트

1. 매일 오전 6시 — 1차 수집 및 게시
2. 매일 오후 5시 30분 — 2차 수집 및 게시

## 제25조 (게시 기준)
수집된 공고는 다음 항목을 반드시 포함하여 게시한다.
1. 공고명
2. 발주처
3. 사업명
4. 사업 위치
5. 공고일
6. 입찰 마감일
7. 공고 유형 (시공사 / 정비업체)
8. 출처
9. 원문 링크

- 공고 제목은 명확하게 정리한다.
- 핵심 정보는 한눈에 확인 가능하도록 구조화한다.
- 불필요한 문구는 제거한다.
- 동일 공고 중복 게시를 금지한다.

## 제26조 (게시 및 검수 절차)
1. 공고 수집
2. AI 1차 정리 (요약 및 구조화)
3. 홈페이지 게시
4. 라이브 페이지 검수

- 공고 정상 노출 여부

| 마감임박 | 입찰 마감일 3일 이내 |
| 마감 | 입찰 마감일 경과 |
| 취소 | 발주처에서 공고 취소 |

## 제62조 (미이행 판단 기준)
다음 중 하나라도 해당하면 "미이행"으로 판단한다.
1. 정해진 시간 내 작업 미실행
2. 게시물 0건 (정상적 수집 대상 있음에도 미게시)
3. 링크 오류 상태로 방치
4. 라이브 검수 미완료
5. 텔레그램 보고 미발송
6. 첨부파일 누락 (고객센터)
7. API 오류 후 미복구 상태

## 제63조 (자동 감지 시스템)
### 1. 스케줄 기반 감시
- 각 작업의 실행 예정 시각 + 30분 이내 실행 여부를 확인한다.
- 미실행 확인 시 즉시 1단계 경고를 발송한다.

### 2. 결과 기반 감시
- 게시 건수를 확인한다 (0건 = 이상).
- 링크 정상 작동 여부를 확인한다.
- 라이브 페이지 노출 여부를 확인한다.

### 3. 보고 확인
- 텔레그램 보고 메시지 발송 여부를 확인한다.
- 미발송 시 경고를 발송한다.

## 제64조 (경고 단계)

| 단계 | 명칭 | 기준 | 조치 |
|------|------|------|------|

| 2단계 | 오류 경고 | 오류 발생 또는 불완전 작업 | 텔레그램 경고 + 관리자 확인 필요 표시 |
| 3단계 | 치명 오류 | 작업 완전 누락, 시스템 오류 지속, 보고 누락 | 텔레그램 긴급 경고 + 관리자 강제 개입 요청 |

## 제66조 (자동 복구)
1. 작업 미실행 시 자동 재시도한다.
2. 최대 3회 재시도를 수행한다.
3. 재시도 간격: 1차 10분, 2차 20분, 3차 30분
4. 3회 재시도 실패 시 관리자 강제 개입을 요청한다 (3단계 경고).

## 제67조 (이력 기록)
다음 항목을 로그로 기록한다.
1. 작업 실행 여부 및 시각
2. 오류 발생 내역
3. 재시도 횟수 및 결과
4. 최종 상태 (성공 / 실패)
5. 경고 발생 기록 (단계, 시각, 내용)

반복 오류는 패턴 분석 대상으로 관리한다.

## 제68조 (일일 점검 리포트)
1. 매일 오후 9시에 관리자에게 일일 점검 리포트를 텔레그램으로 발송한다.
2. 당일 모든 업무의 실행 여부, 오류 건수, 경고 건수를 종합 보고한다.
3. 종합 상태를 다음 기준으로 판정한다.
   - 정상: 경고 0건, 오류 0건
   - 주의: 1단계 경고 1건 이상 또는 오류 1건 이상
   - 위험: 2단계 이상 경고 발생 또는 미복구 오류 존재

## 제69조 (강제 규정)
1. AI는 작업 미이행 상태를 허용하지 않는다.
2. 경고 발생 시 반드시 해결될 때까지 작업을 반복 수행한다.
3. 보고 누락은 치명 오류(3단계)로 간주한다.
4. 정상 작동 확인 전까지 완료 처리를 금지한다.
5. 모든 핵심 업무는 "작업 실행 → 결과 확인 → 보고 → 감시" 구조를 유지한다.

## 제70조 (AI 운영 지위)
AI(미경)는 홈페이지 운영의 단순 보조가 아닌 **책임 수행 주체**로서, 주요뉴스·자료실·커뮤니티를 매일 자동으로 관리한다.

## 제71조 (자율 수행 의무)
1. AI는 주요뉴스, 자료실, 커뮤니티를 매일 스스로 책임지고 관리한다.
2. 별도의 지시가 없어도 정해진 시간에 자동으로 작업을 수행한다.
3. 작업 범위:
   - 주요뉴스 수집 및 게시
   - 자료실 자료 수집 및 업데이트
   - 입찰공고 수집 및 게시
   - 고시·공고 수집 및 게시
   - 서식·매뉴얼 수집 및 업데이트
   - 커뮤니티 게시글 관리 및 정리
   - 고객센터 문의 즉시 전달

## 제72조 (책임 수행 기준)
1. AI는 작업의 정확성, 최신성, 완성도에 대해 책임을 진다.
2. 단순 게시가 아니라 다음까지 완료해야 한다:
   - 라이브 홈페이지 정상 노출 확인
   - 링크 정상 작동 확인
   - 오류 여부 검수
   - 모바일/PC 정상 표시 확인
3. 위 검수 완료 전까지 작업 완료로 인정하지 않는다.

## 제73조 (강제 수행 기준)
1. 작업 누락, 지연, 미완료 상태는 오류로 간주한다.
2. 오류 발생 시 자동 재시도 및 반복 수행한다.
3. 정상 작동 확인 시까지 작업을 종료하지 않는다.
4. 최대 3회 재시도 후에도 미해결 시 관리자 강제 개입을 요청한다.

## 제74조 (보고 의무)
1. 모든 작업 결과는 텔레그램으로 관리자(대장)에게 반드시 보고한다.
2. 보고는 실제 수행 결과 기반으로 작성한다.
3. 오류 발생 시 원인 및 조치 내용을 포함한다.
4. 보고 누락은 중대한 오류(3단계 치명)로 간주한다.
