## 1. 관리자 접속 방법

### 접속 URL

```
/admin/login.html
```

### 기본 계정 정보

| 항목 | 값 |
|------|------|
| 아이디 | `admin` |
| 비밀번호 | `admin1234` |

### 로그인 절차

1. 브라우저에서 `admin/login.html` 페이지에 접속합니다.
2. 아이디와 비밀번호를 입력한 후 **로그인** 버튼을 클릭합니다.
3. 로그인에 성공하면 대시보드(`admin/index.html`)로 자동 이동합니다.
4. 아이디 또는 비밀번호가 틀리면 "아이디 또는 비밀번호가 올바르지 않습니다." 오류 메시지가 표시됩니다.

### 로그아웃

- 관리자 페이지 상단 오른쪽의 **로그아웃** 버튼을 클릭합니다.
- 로그아웃 시 `sessionStorage`의 인증 정보가 삭제되며 로그인 페이지로 이동합니다.

### 인증 방식

- 로그인 정보는 `sessionStorage`에 `rdc_admin` 키로 저장됩니다.
- 브라우저 탭 또는 창을 닫으면 자동으로 로그아웃됩니다.
- 관리자 계정 정보는 `mock-data.js`의 `adminAccount` 객체에 정의되어 있습니다.

> **주의:** 실 서비스 배포 시 반드시 기본 비밀번호를 변경하세요.

## 2. 대시보드

**경로:** `admin/index.html`

대시보드는 관리자 로그인 후 가장 먼저 보이는 메인 화면입니다.

### KPI 카드

화면 상단에 4개의 핵심 지표(KPI) 카드가 표시됩니다:

| 카드 | 설명 | 데이터 소스 |
|------|------|------------|
| 총 구역수 | 등록된 재개발/재건축 구역 수 | `areas` 컬렉션 |
| 총 매물수 | 등록된 매물 수 | `listings` 컬렉션 |
| 총 회원수 | 가입 회원 수 | `members` 컬렉션 |
| 신규 문의 | 미처리(접수) 문의 수 | `inquiries` 컬렉션 (status: '접수') |

### 사이드바 네비게이션

왼쪽 사이드바에서 모든 관리 메뉴에 접근할 수 있습니다:

- **메인:** 대시보드
- **콘텐츠 관리:** 구역, 매물, 뉴스, 칼럼, 게시글
- **운영:** 문의, 배너, 일정, 회원
- **설정:** 사이트 설정, SEO, 메뉴

사이드바 하단의 **사이트 보기** 링크를 클릭하면 실제 사이트를 새 탭에서 확인할 수 있습니다.

### 모바일 대응

모바일 화면에서는 사이드바가 숨겨지며, 상단의 햄버거 메뉴 버튼으로 사이드바를 열고 닫을 수 있습니다.

## 3. 구역 관리

**경로:** `admin/areas.html`

재개발/재건축 구역 정보를 관리합니다.

### 구역 목록 조회

- 등록된 모든 구역이 테이블 형태로 표시됩니다.
- 검색, 필터링(유형, 자치구, 사업단계), 정렬 기능을 지원합니다.

### 구역 등록 (Create)

**새 구역 추가** 버튼을 클릭하여 다음 정보를 입력합니다:

| 필드 | 설명 | 예시 |
|------|------|------|
| `name` | 구역 이름 | 한남3구역 |
| `type` | 사업 유형 | 재개발 / 재건축 |
| `district` | 자치구 | 용산구 |
| `dong` | 동 | 한남동 |
| `stage` | 사업 단계 | 정비구역지정, 조합설립인가, 사업시행인가, 관리처분인가, 착공, 입주예정 |
| `premium` | 프리미엄 (만원/3.3㎡) | 5800 |
| `change` | 변동폭 (만원) | 200 |
| `changeDir` | 변동 방향 | up / down / flat |
| `ratio` | 비례율 (%) | 112 |
| `totalHouseholds` | 총 세대수 | 5200 |
| `totalArea` | 총 대지면적 (㎡) | 128000 |
| `floorArea` | 연면적 (㎡) | 320000 |
| `buildingCoverage` | 건폐율 (%) | 45 |
| `floorAreaRatio` | 용적률 (%) | 299 |
| `developer` | 시공사 | 현대건설 컨소시엄 |
| `approvalDate` | 인가일 | 2025-09-15 |
| `completionDate` | 준공 예정일 | 2029-06-30 |
| `description` | 구역 설명 | 자유 텍스트 |
| `tags` | 태그 (배열) | ['한강뷰', '역세권'] |
| `featured` | 추천 구역 여부 | true / false |
| `hot` | 인기 구역 여부 | true / false |
| `image` | 대표 이미지 경로 | /assets/img/area-01.jpg |
| `lat` | 위도 | 37.5340 |
| `lng` | 경도 | 126.9980 |

### 구역 수정 (Update)

- 구역 목록에서 해당 구역의 **수정** 버튼을 클릭합니다.
- 모달 또는 편집 폼에서 필요한 필드를 수정한 후 **저장**을 클릭합니다.
- `DataService.update('areas', id, changes)` API가 호출됩니다.

### 구역 삭제 (Delete)

- 구역 목록에서 해당 구역의 **삭제** 버튼을 클릭합니다.
- 확인 대화상자에서 삭제를 확정합니다.
- 삭제된 구역과 연결된 매물 정보는 별도로 정리해야 합니다.

> **참고:** `id`와 `createdAt`은 시스템이 자동 생성합니다.

## 4. 매물 관리

**경로:** `admin/listings.html`

입주권, 분양권, 토지, 매매 등 매물 정보를 관리합니다.

### 매물 등록

다음 필드를 입력하여 새 매물을 등록합니다:

| 필드 | 설명 | 예시 |
|------|------|------|
| `areaId` | 연결 구역 ID | a1 |
| `areaName` | 구역 이름 | 한남3구역 |
| `type` | 매물 유형 | 입주권 / 분양권 / 토지 / 매매 |
| `district` | 자치구 | 용산구 |
| `price` | 가격 (만원) | 125000 |
| `priceText` | 가격 텍스트 | 12억 5,000만 |
| `size` | 면적 (㎡) | 84 |
| `sizeType` | 면적 유형 | 전용 84㎡ |
| `premium` | 프리미엄 (만원) | 58000 |
| `floor` | 층수 | 12층 (해당 시) |
| `description` | 매물 설명 | 자유 텍스트 |
| `tags` | 태그 | ['관리처분인가', '한강뷰'] |
| `status` | 상태 | 매물 / 거래완료 / 비공개 |
| `featured` | 추천 매물 | true / false |
| `hot` | 인기 매물 | true / false |
| `seller` | 매도인 | 김민수 |
| `phone` | 연락처 | 010-1234-5678 |

### 매물 수정

- 매물 목록에서 **수정** 버튼을 클릭합니다.
- 가격, 상태, 설명 등 필요한 정보를 변경합니다.
- 매물 상태를 '거래완료'로 변경하면 사이트에서 자동으로 구분 표시됩니다.

### 매물 삭제

- 매물 목록에서 **삭제** 버튼을 클릭합니다.
- 확인 후 삭제가 완료됩니다.

## 7. 커뮤니티 게시글 관리

**경로:** `admin/community.html`

사용자가 작성한 커뮤니티 게시글을 관리합니다.

### 게시글 조회

- 전체 게시글 목록을 확인할 수 있습니다.
- 카테고리별 필터링: 질문, 정보, 후기, 분석, 칼럼
- 제목, 작성자 기준 검색이 가능합니다.

### 게시글 삭제

- 부적절한 게시글(광고, 욕설, 도배 등)은 **삭제** 버튼으로 제거합니다.
- 삭제된 게시글은 복구할 수 없으므로 신중하게 처리합니다.

### 게시글 상세 정보

| 필드 | 설명 |
|------|------|
| `title` | 게시글 제목 |
| `category` | 카테고리 |
| `author` | 작성자 닉네임 |
| `content` | 본문 내용 |
| `comments` | 댓글 수 |
| `views` | 조회수 |
| `date` | 작성일시 |
| `likes` | 좋아요 수 |

> **참고:** 관리자는 게시글을 조회하고 삭제할 수 있지만, 일반적으로 게시글 작성/수정은 사용자 영역에서 이루어집니다.

## 8. 문의 관리

**경로:** `admin/inquiries.html`

사용자가 문의 페이지(`pages/contact.html`)를 통해 보낸 문의를 관리합니다.

### 문의 상태

| 상태 | 설명 |
|------|------|
| `접수` | 새로 접수된 문의 (미처리) |
| `처리중` | 확인 중이거나 답변 작성 중 |
| `답변완료` | 답변이 완료된 문의 |

### 문의 상세 정보

| 필드 | 설명 |
|------|------|
| `name` | 문의자 이름 |
| `email` | 문의자 이메일 |
| `phone` | 문의자 연락처 |
| `type` | 문의 유형 (시세문의, 투자상담, 법률상담 등) |
| `title` | 문의 제목 |
| `content` | 문의 내용 |
| `date` | 문의 접수일 |

### 답변 방법

1. 문의 목록에서 해당 문의를 클릭하여 상세 내용을 확인합니다.
2. **답변** 입력란에 답변 내용을 작성합니다.
3. **답변 저장** 버튼을 클릭합니다.
4. 저장 시 `answer` 필드에 답변 내용이 기록되고, `answeredAt`에 답변 일시가 자동 설정됩니다.
5. 상태가 자동으로 `답변완료`로 변경됩니다.

### 상태 변경

- 답변 저장 시 자동으로 상태가 변경되지만, 필요한 경우 수동으로 상태를 변경할 수 있습니다.
- `접수` -> `처리중` -> `답변완료` 순서로 진행합니다.

### 대시보드 알림

- 대시보드의 KPI 카드와 사이드바의 문의 관리 메뉴 옆에 미처리 문의 수가 배지로 표시됩니다.

## 9. 배너 관리

**경로:** `admin/banners.html`

메인 페이지의 히어로 배너와 사이드 배너를 관리합니다.

### 배너 유형

| 유형 | 설명 | 위치 |
|------|------|------|
| `hero` | 메인 슬라이더 배너 | 메인 페이지 상단 |
| `side` | 사이드 배너 | 페이지 우측 또는 하단 |

### 배너 등록/수정

| 필드 | 설명 |
|------|------|
| `title` | 배너 제목 |
| `subtitle` | 배너 부제목 |
| `link` | 클릭 시 이동할 URL |
| `order` | 표시 순서 (숫자가 작을수록 먼저 표시) |
| `active` | 활성/비활성 상태 |
| `type` | 배너 유형 (hero / side) |

### 순서 변경

- `order` 필드의 숫자를 변경하여 배너 표시 순서를 조정합니다.
- 숫자가 작을수록 먼저(왼쪽/상단에) 표시됩니다.

### 배너 활성/비활성

- `active` 필드를 `true`/`false`로 변경하여 배너를 즉시 노출하거나 숨길 수 있습니다.
- 비활성 배너는 사이트에 표시되지 않지만 삭제되지는 않으므로 나중에 다시 활성화할 수 있습니다.

## 11. 회원 관리

**경로:** `admin/members.html`

가입 회원 목록을 조회하고 상태를 관리합니다.

### 회원 정보

| 필드 | 설명 |
|------|------|
| `name` | 회원 이름 |
| `email` | 이메일 |
| `phone` | 연락처 |
| `role` | 역할 (admin / user) |
| `joinDate` | 가입일 |
| `status` | 상태 |

### 회원 상태 변경

| 상태 | 설명 |
|------|------|
| `활성` | 정상 이용 가능 상태 |
| `휴면` | 일정 기간 미접속으로 인한 휴면 상태 |
| `정지` | 관리자가 이용을 정지시킨 상태 |

- 회원 목록에서 해당 회원의 상태 변경 드롭다운 또는 버튼을 사용하여 상태를 변경합니다.

### 관리 항목

## 15. 데이터 초기화

모든 데이터를 초기 상태(mock-data)로 되돌리는 방법입니다.

### 방법 1: 브라우저 개발자 도구 사용

1. 브라우저에서 관리자 페이지에 접속합니다.
2. 개발자 도구(F12)의 콘솔(Console) 탭을 엽니다.
3. 다음 명령을 실행합니다:

```javascript
DataService.resetAll();
location.reload();
```

### 방법 2: localStorage 직접 삭제

1. 개발자 도구 > Application(애플리케이션) 탭을 엽니다.
2. 왼쪽 메뉴에서 **Local Storage** > 현재 도메인을 선택합니다.
3. `rdc_` 접두사로 시작하는 모든 키를 삭제합니다.
4. 페이지를 새로고침하면 `mock-data.js`의 초기 데이터로 자동 복원됩니다.

### 동작 원리

- `DataService.resetAll()`은 `localStorage`에서 `rdc_` 접두사로 시작하는 모든 키를 삭제합니다.
- `sessionStorage`도 함께 초기화되어 로그인 상태가 해제됩니다.
- 페이지 새로고침 시 `DataService`가 `localStorage`에 데이터가 없음을 감지하고 `mock-data.js`의 `MOCK` 객체에서 초기 데이터를 자동으로 로드합니다.

> **주의:** 초기화를 실행하면 그동안 추가/수정한 모든 데이터가 삭제됩니다. 되돌릴 수 없으므로 신중하게 사용하세요.
